# Project sources and credits

The installable files live under [config](config/). The project supplies the shared instructions, selects the agents and integrates commands and reference material from the sources below. The MIT license covers this collection. Upstream copyright notices appear in the [license file](LICENSE).

| Material | Source |
| --- | --- |
