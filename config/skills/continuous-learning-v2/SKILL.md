# Continuous learning

When the user asks to retain a lesson, identify the decision, the circumstances where it helped and the evidence for it. Ask whether it should apply to this project or more broadly. Draft a short note in the conversation.

Use only the conversation and files the user selected for this task. Remove identifying details, keys, URLs with private parameters and customer content from the draft. Saving the note requires approval of its content and destination. Cross-project sharing requires its own approval.

The upstream Everything Claude Code project also offers an observation-based system. This distribution ships Markdown guidance only. It does not bundle that system's observer, CLI or storage. Installing the optional upstream integration and consenting to its data collection are separate decisions.
